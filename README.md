## Ently
---
#### Tiny but mighty JS library for building simple web applications

Ently (from "ant" – small but powerful) is a **minimalistic JS library** designed to help you **quickly create and manage web apps** without the overhead of large frameworks.  

It comes with **ready-to-use styles and UI components** like **buttons, cards, navigation bars, sidebars, and forms**, allowing you to **build beautiful, consistent interfaces** with minimal effort. Ently also supports **themes, color management, and material design**, making it easy to customize the look and feel of your applications.

### Using Ently without downloading

If you don’t want to download the main JS file, you can include it directly in your HTML via CDN:

```html
<script src="https://cdn.jsdelivr.net/gh/asvistun5/Ently@main/ently/main.js"></script>
```
